# Legenda® — landing

Static landing for Legenda®, Tashkent.
Below 768px the page stays the 390px mobile layout. From 768px the same sections sit in a desktop layout.
Russian is the default copy. Uzbek is the second language, switched with RU / UZ in the header.

```bash
cd ~/legenda-landing && python3 -m http.server 5173
```
